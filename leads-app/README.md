# База лидов

Локальное приложение для Windows: загрузка скринов из CRM → распознавание → база лидов → статусы отработки → экспорт в Excel.
Данные не покидают компьютер: распознавание (Tesseract) и база (SQLite) работают офлайн.

## Установка

**Готовая сборка (рекомендуется):** GitHub → Actions → «leads-app build» → последний успешный запуск →
Artifacts → **LeadsBase** → скачать, распаковать, запустить `LeadsBase.exe`. Python и Tesseract не нужны.

**Из исходников (для разработки):**

1. **Python 3.11+** — https://www.python.org/downloads/ (при установке отметить «Add python.exe to PATH»).
2. **Tesseract OCR** — https://github.com/UB-Mannheim/tesseract/wiki → установщик для Windows.
   В установщике в разделе *Additional language data* отметить **Russian**.
3. Скачать папку `leads-app` на компьютер.

## Запуск

Двойной щелчок по `start.bat`. Откроется браузер с адресом http://127.0.0.1:8765
(сервер доступен только с этого компьютера). Закрыть программу — закрыть чёрное окно.

## Как пользоваться

1. **Загрузка скринов** — перетащить скрины, выбрать файлы или вставить из буфера (Win+Shift+S → Ctrl+V).
   Программа покажет распознанные строки, их можно поправить. Дубли (телефон уже в базе) по умолчанию пропускаются,
   можно выбрать «Обновить в базе». Затем «Сохранить в базу».
2. **База** — статус, дата «Перезвонить», комментарий меняются прямо в таблице.
   - **Календарь**: клик по дню — начало периода, второй клик — конец; клик по названию месяца — весь месяц;
     кнопки «Сегодня», «7 дней», «Этот месяц» и т.д. Точка под числом — в этот день есть лиды.
   - **Фильтры колонок** (▾ в заголовке): как в Excel — галочки, можно выбрать несколько значений, поиск по списку.
     Активный фильтр подсвечен и показывает число выбранных значений.
   - Плашки статусов — счётчики за выбранный период; клик добавляет/убирает статус в фильтре.
   - «Перезвонить сегодня» — звонки на сегодня и просроченные. «Сбросить фильтры» — всё обратно.
3. **Экспорт в Excel** — выгружает ровно то, что видно в таблице (период + фильтры).
   Период не выбран — весь период. Имя файла содержит период: `leads_2026-10-01_2026-10-10.xlsx`.
4. **Отчёт по отработке** — выгруженный файл и есть бланк отчёта (см. ниже).

## Excel-отчёт по отработке

Один формат для выгрузки и загрузки:

| Телефон | Компания / ФИО | Форма | Сумма запроса | Дата лида | **Статус** | **Перезвонить** | **Комментарий** |
| --- | --- | --- | --- | --- | --- | --- | --- |
| серые — справочно, не менять | | | | | список статусов | дата и время | текст |

1. «База» → фильтр (например, «Новый») → «Экспорт в Excel».
2. Оператор заполняет три белые колонки.
3. «Отчёт по отработке» → загрузить файл → программа покажет «было → стало» и ошибки → «Применить отмеченные».

Правила загрузки:
- клиент ищется по телефону, если телефона нет — по точному совпадению «Компания / ФИО»;
- статус можно писать своими словами: «отказ», «успех», «не проходит» — программа приведёт к справочнику;
- «Перезвонить» без даты не применяется; дата без времени = 10:00;
- пустой комментарий не стирает старый;
- строки без изменений и не найденные клиенты пропускаются (показываются в списке);
- принимаются и чужие отчёты, если в них есть колонки «Телефон» (или «Клиент/ФИО») и «Статус».

Статусы: Новый, В работе, Перезвонить (нужна дата), Успешно, Отказ клиента, Не проходит по критериям.

## Данные

База — файл `data/leads.db`. Дубли определяются по телефону.

**Автобэкап:** при запуске и раз в сутки, пока программа открыта, — `data/backups/leads_ГГГГ-ММ-ДД.db`,
хранятся 30 последних. Дата последнего бэкапа видна в правом верхнем углу.
Восстановление: закрыть программу, заменить `data/leads.db` файлом из `backups` (переименовать в `leads.db`).

## Что распознаётся

Таблица «Операционная статистика по лидам»: колонки «Дата лида», `lead_phone`, «форма организации»,
«запрошенная сумма», «компания лида». Остальные колонки игнорируются. На скрине должна быть строка заголовков.
Скрин без таблицы (сообщение) — запасной режим: ищутся телефон, сумма, ИП/ООО, дата.

## Разработка

```
pip install -r requirements.txt pytest httpx
python -m pytest tests     # тесты (нужен Tesseract с русским языком)
python run.py              # запуск
```

| Файл | Назначение |
| --- | --- |
| `app/ocr.py` | Распознавание скринов и нормализация (телефон, сумма, дата, форма) |
| `app/db.py` | База SQLite, статусы |
| `app/main.py` | API |
| `app/export.py` | Экспорт в Excel и чтение отчёта |
| `app/backup.py` | Автобэкап базы |
| `run.py` | Точка входа (сервер + браузер + бэкап) |
| `../.github/workflows/leads-app-build.yml` | Сборка LeadsBase.exe на Windows |
| `app/static/` | Интерфейс |
| `tests/` | Тесты и генераторы тестовых скринов (данные вымышленные) |
