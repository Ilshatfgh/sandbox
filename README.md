# Claude с нуля

Интерактивный 8-недельный курс по Claude для тех, кто никогда не пользовался нейросетями.
Один HTML-файл: открывается двойным щелчком в любом браузере, без регистрации и без интернета.

**Автор:** Ильшат Фахритдинов

## Что внутри

- 9 модулей (вводный модуль 0 и 8 основных), 39 уроков, 56 готовых запросов
- конструктор запроса, тесты по модулям, словарь терминов, план на 8 недель
- прогресс прохождения сохраняется в браузере пользователя
- раздел «Об авторе» с фотографией
- светлая и тёмная тема, адаптация под телефон

## Структура репозитория

| Путь | Назначение |
| --- | --- |
| `src/data1.js` | Контент: модули 0–3 (уроки, промпты, задания, тесты) |
| `src/data2.js` | Контент: модули 4–8, план на 8 недель, словарь, данные автора (имя, фото, списки нейросетей) |
| `src/app.js` | Логика: навигация, прогресс, копирование, конструктор, тесты |
| `src/head.html` | Стили и название страницы |
| `src/body.html` | Каркас страницы |
| `build.sh` | Сборка в один файл |
| `dist/claude-s-nulya.html` | Готовый продукт |

## Как собрать

```bash
bash build.sh
```

Результат появится в `dist/claude-s-nulya.html`.

## Как обновлять

- Текст уроков, промпты, тесты: `src/data1.js` и `src/data2.js`
- Данные автора: объект `AUTHOR` в конце `src/data2.js` (фото хранится там же как data URI)
- Внешний вид: `src/head.html`

Названия моделей и тарифы Claude меняются примерно раз в квартал. После правок
обновите пометку «актуально на …» внизу главной страницы (`src/app.js`, функция `renderHome`).
